# Omnisend for SureCart Add-On

Integrates SureCart with Omnisend so store contacts, orders, and product data can be used for personalized email and SMS marketing.

Requires [SureCart](https://wordpress.org/plugins/surecart/) and the [Omnisend](https://wordpress.org/plugins/omnisend/) plugin.

WordPress plugin: https://wordpress.org/plugins/omnisend-for-surecart-add-on/
